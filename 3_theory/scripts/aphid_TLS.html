Aphid TLS

Cereal Aphid TLS

In their recent preprint, Noble et al. (n.d.) used time to death data from Li et al. (2023) to construct Bayesian thermal tolerance landscapes using the bayesTLS package. Conveniently, the three species in the paper (Metopolophium dirhodum, Sitobion avenae and Rhopalosiphum padi) are the same three species we extracted abundnace data for from 15 sites in the Rothamsted insect survey (rothamsted_data_readin.qmd). For future use, we replicate their analysis (found at https://daniel1noble.github.io/bayesTLS/#sec-aphids) here.

Construct 4PL TLS Model

We use the Noble et al. code here to construct a 4PL TLS model. Note that

# Species effects on z and CTmax with a temperature
# slope on k, but we constrain the asymptotes to be constant (up = ~ 1, low = ~ 1).
# Letting up/low vary by species x temperature overfits here and there is littl evidence up 
# and low vary dramatically with temperature.
priors_age <- make_4pl_priors(aphid_std)

sp  <- c("speciesM_dirhodum", "speciesR_padi", "speciesS_avenae")
dev <- c("age6", "age12",
         "speciesR_padi:age6",   "speciesR_padi:age12",
         "speciesS_avenae:age6", "speciesS_avenae:age12")

p_final <- priors_age[priors_age$nlpar != "mid", ] +
  # CTmaxdev: species baselines and deviations are both expected near 0 °C,
  # so one class-level prior works; slightly tighter on the deviations
  prior(normal(0, 2), class = "b", nlpar = "CTmaxdev") +
  do.call(c, lapply(dev, \(cf) set_prior("normal(0, 1)", class = "b",
                                         nlpar = "CTmaxdev", coef = cf))) +
  # logz: species baselines centered at z ≈ 4 °C (95% ~1.5–10 °C)...
  do.call(c, lapply(sp,  \(cf) set_prior("normal(1.39, 0.5)", class = "b",
                                         nlpar = "logz", coef = cf))) +
  # ...age/interaction terms are multiplicative changes in z, centered at no change
  prior(normal(0, 0.5), class = "b", nlpar = "logz")
